# CatacombsOfTheCastle

3D top-down action game на Unity с системой инвентаря, стрельбой, волнами врагов, состояниями ИИ и внедрением зависимостей через VContainer.

🎮 Скачать игру / посмотреть скрины: 

🎥 Видео геймплея: https://rutube.ru/video/df30bdb3e9d0f0b1579741e7bbbc7d1b/

🛠️**Основные механики:**

 _Игрок_ 
* Управление реализовано через Unity **Input System**.
* Передвижение персонажа с учетом физики **Rigidbody**.

 Игрок может:
* перемещаться по уровню;
* подбирать предметы;
* использовать инвентарь;
* открывать решётки;
* лечиться;
* стрелять по врагам.

_Камера_
* Камера следует за персонажем с помощью **Cinemachine**.

_Инвентарь и сохранение_
* В игре реализована система инвентаря.
* ID собранных предметов сохраняются в **PlayerPrefs**.
* Состав инвентаря хранится в **JSON-файле**.
* Модели предметов инвентаря прописаны в **ScriptableObjects**.

_Окружение_
* На уровне присутствуют опасные зоны, например пол с лавой, который наносит урон игроку.
* Тип поверхности определяется по слою объекта, что используется для обработки взаимодействия с полом.

_Враги_
* На уровне есть объект, отвечающий за спавн волн врагов.

У врагов есть характеристики:
* здоровье;
* сила урона.
* Поведение врагов реализовано через паттерн **State Machine**.
* Основные состояния врага: преследование, атака, смерть.

_Стрельба и оптимизация_
* Игрок может стрелять.
* Для пуль и врагов используется **Object Pooling**, что позволяет переиспользовать объекты и снижать нагрузку на производительность.

_UI_
* Отображение здоровья игрока реализовано через **Canvas**.
* Обновление UI построено на системе событий.
* Реализованы главное меню, меню паузы, экран окончания игры.

_Звук_
* фоновая музыка в главном меню;
* фоновая музыка на уровнях;
* звуки перемещения игрока;
* звуки подбора предметов;
* звуки стрельбы;
* звуки атак врагов;
* звуки нажатия на кнопки.

_Архитектура_
* Для внедрения сервисов используется **VContainer**.
* Существует отдельный Bootstrap level, в котором инициализируются общие сервисы проекта.

⚙️ **Техническая информация:**
* Visual studio 2026
* Unity 6000.3.10f
* Canvas UI 
* Unity Input System
* VContainer (Dependency Injection)
* Object Pooling
* State Machine
* ScriptableObjects
* Cinemachine
* PlayerPrefs
* Сохранение прогресса в файл *.json
